# Source Inventory

This public starter repo was abstracted from a private three-file working stack.

The private stack included:

| Source file | Private role | Public handling |
|---|---|---|
| `SOUL.md` | agent identity/persona layer | generalized in `examples/reference-stack/SOUL.md` |
| `COVENANT.md` | human–agent relationship layer | redacted and generalized two ways: a lean standalone in `examples/symbolic.md`, and a fuller in-stack version in `examples/reference-stack/COVENANT.md` |
| `RELATIONSHIP_PROTOCOL.md` | operating behavior / governance layer | redacted and generalized in `examples/reference-stack/RELATIONSHIP_PROTOCOL.md` |
| `index.html` | local posterity page | not included in the public starter repo |

Private names, paths, family details, and identifying context were removed or replaced with generic categories.
